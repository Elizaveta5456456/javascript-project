Замечания и доработки

Этот документ фиксирует замечания, выявленные в процессе тестирования сайта,
и описывает выполненные доработки.

1. Визуальные замечания

1.1 Hero-блок
Замечание: на мобильных устройствах с шириной экрана менее 375px заголовок
выходил за пределы экрана.
Решение: уменьшен размер шрифта заголовка для мобильных до 26px,
добавлен перенос слов через word-break.

1.2 Каталог
Замечание: на планшетах (768px) карточки каталога были слишком мелкими,
текст категорий читался плохо.
Решение: изменена сетка с 3 колонок на 2 для планшетного разрешения,
увеличен размер шрифта в карточках.

1.3 Галерея коллекций
Замечание: фотографии коллекций на десктопе отображались с разным соотношением сторон,
что создавало визуальный хаос.
Решение: все изображения приведены к единому соотношению через object-fit: cover
с фиксированной высотой контейнера.

2. Функциональные замечания

2.1 Форма обратной связи
Замечание: пользователь мог отправить пустую форму.
Решение: добавлен атрибут required на поля имени и телефона.

2.2 Навигация
Замечание: на мобильных устройствах бургер-меню не закрывалось после нажатия на ссылку.
Решение: добавлен обработчик onClick, который закрывает меню при переходе по якорной ссылке.

2.3 Якорные ссылки
Замечание: при переходе по якорным ссылкам контент перекрывался фиксированным хедером.
Решение: добавлен scroll-margin-top для секций, равный высоте хедера (80px).

3. Производительность

3.1 Изображения
Замечание: общий вес страницы превышал 4 МБ из-за несжатых фотографий.
Решение: все изображения сжаты и конвертированы, общий вес страницы снижен до 1.8 МБ.

3.2 Шрифты
Замечание: шрифт Inter загружался полностью, хотя использовались только 3 начертания.
Решение: подключены только нужные начертания (500, 700, 900), что уменьшило объём загрузки.

4. Кроссбраузерность

Проверка проводилась в Chrome, Firefox и Safari.
Все элементы отображаются корректно во всех браузерах.
Адаптивная верстка работает на разрешениях от 360px до 1920px.
