# Лендинг для магазина уличной одежды Design Gang

Современный одностраничный лендинг для магазина уличной одежды, разработанный на React. Сайт демонстрирует каталог товаров, коллекции бренда и предоставляет форму для сбора заявок от покупателей. Проект имеет модульную структуру, адаптивный дизайн и ориентирован на конверсию посетителей в заявки.

## Запуск проекта

1. Предварительные требования
   `Node.js версии 14.x или выше`
   `npm (поставляется с Node.js)`
   `Браузер для просмотра`

2. Установка и запуск
   Клонирование и переход в директорию проекта
   `git clone <URL-репозитория>`
   `cd <название-папки-проекта>`

3. Установка зависимостей
   `npm install`

4. Запуск в режиме разработки
   `npm start`
   Приложение откроется автоматически в браузере

## Функционал компонентов

### Header (Header.jsx)
- Логотип бренда Design Gang
- Навигационное меню по разделам сайта
- Кнопка "купить"
- Адаптивное бургер-меню для мобильных устройств

### Hero (Hero.jsx)
- Главный баннер с названием бренда и слоганом
- Кнопки CTA: "Смотреть каталог" и "Новая коллекция"
- Градиентный фон в уличной стилистике

### Catalog (Catalog.jsx)
- Карточки категорий товаров с изображениями
- Эффект увеличения при наведении
- 6 категорий: худи, футболки, брюки, куртки, аксессуары, новинки

### Collection (Collection.jsx)
- Галерея фотографий из актуальной коллекции
- Сетка из 8 фотографий лукбука

### About (About.jsx)
- Преимущества бренда с нумерованными карточками
- 6 ключевых причин выбрать Design Gang

### ContactForm (ContactForm.jsx)
- Форма обратной связи для заказов
- Поля: имя, телефон
- Валидация обязательных полей

### Footer (Footer.jsx)
- Контактная информация (город, email)
- Ссылки на социальные сети (Telegram, VK, Нельзаграм)

## Стили и дизайн

- CSS для каждого компонента: изолированные стили без конфликтов
- Адаптивный дизайн: полная поддержка мобильных устройств и планшетов
- Цветовая схема: фон (#F9F9F9, #E9EAEE), текст (#121315), бренд (#0C75F7)
- Типографика: шрифт Inter в начертаниях 400, 500, 700, 900
- Интерактивность: эффекты при наведении на карточки, плавные переходы
